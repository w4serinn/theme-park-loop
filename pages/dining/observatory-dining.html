天文台

星見ダイナー「ふたご座の食卓」

天文台の展望テラス下に位置する夜景付きのダイナー。星座表をテーブルに埋め込んだインテリアが人気で、夜間観測の前後に訪れる学生が絶えません。天体観測士が「観測中に食べたいもの」として挙げたメニューが揃います。

ディナー デザート ドリンク

ディナー

  • 観測士のコースランチ

    天文台研究員が「夜間観測の前に食べたい」と語った料理を元にシェフが組み立てたコース。スープ・メイン・パン・デザートの4品構成で、ゆっくりと星を待つ夜に相応しい一食です。

    ¥1,200（税込）

    内容
    スープ / メイン（ローストポーク or 白身魚 選択） / パン / デザート
    アレルギー
    小麦・乳製品（デザートに含む）。メインの選択時にスタッフへご相談ください。
    魔法効果
    夜間視力がわずかに向上します（4時間）。観測精度が上がるという報告もあります。
    提供時間
    17:00〜（星が見え始める時刻に合わせた夕食コース）

  • 天体望遠鏡ランチBOX

    筒形の容器に入った「詰め込み系」ランチ。上から順に食べ進めると異なる素材が現れる構造が、望遠鏡の接眼レンズを覗くような楽しさを持ちます。

    ¥920（税込）

    内容
    ご飯 / 旬野菜 / 鶏肉または豆腐（選択）/ タレ
    アレルギー
    小麦（タレ）含む。豆腐選択時は大豆含む。
    魔法効果
    なし。食べ進める楽しさが全てです。

デザート

  • 夜空ゼリーデザート「双子星」

    2色（蒼・銀）のゼリーを重ねたグラスデザート。上層に星屑を模した銀糖が散らされ、夜空の情景を食卓に再現。食べ始める前にしばらく眺める来場者が後を絶たない。

    ¥580（税込）

    材料
    果汁（青果） / 生クリーム / ゼラチン / 銀糖（食用）
    アレルギー
    乳製品含む。
    魔法効果
    消化促進（微）。就寝の質がわずかに向上します。観測後の夜食として最適です。

ドリンク

  • 星屑ソーダ「流星の軌跡」

    キラキラと光る銀糖を泡立つソーダに溶かしながら飲む。溶ける速さで「今夜の星見の運」を占うという学生風習があり、夜間観測前後に必ず注文する学生も多い。

    ¥480（税込）

    材料
    炭酸水 / 柑橘シロップ / 銀糖（食用）
    アレルギー
    なし。
    魔法効果
    直感力微向上（1時間）。星との対話に臨む方にぜひ。
