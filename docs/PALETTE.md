# カラーパレット台帳

## コアカラー(不変・承認不要)

全ページ共通で必ず使用する。CSS変数は `styles/tokens.css` で定義済み。

| 変数名 | 色イメージ | 用途 |
|---|---|---|
| `--brass` | 真鍮ゴールド | 歯車・パイプ・装飾のメタル色 |
| `--emerald` | 深緑 | 魔法陣・制服の色 |
| `--ink` | 深紺〜黒 | 背景・基本文字色 |
| `--ember` | 琥珀〜深紅 | 蒸気・魔法の光のアクセント |

## ページアクセント色(承認制)

コア4色以外の色を使いたい場合は、ここに提案を追記してから人間の承認を待つこと。
承認前は実装に使わない。

### 提案中(未承認)

(現在なし)

### 承認済み

(現在なし)

## 提案の書き方(ループ向けフォーマット)

```
### --accent-<用途名> [提案日: YYYY-MM-DD]
- 色: #RRGGBB
- 使用予定ページ:
- 理由:
- コアカラーとの関係(補色/類似色など):
```

承認された場合、人間がこのファイルの「承認済み」に移動し、
`styles/tokens.css` にも変数を追記する。
