# カラーパレット台帳

## コアカラー(不変・承認不要)

全ページ共通で必ず使用する。CSS変数は `styles/tokens.css` で定義済み。

| 変数名 | 色イメージ | 用途 |
|---|---|---|
| `--brass` | 真鍮ゴールド | 歯車・パイプ・装飾のメタル色 |
| `--emerald` | 深緑 | 魔法陣・制服の色 |
| `--ink` | 深紺〜黒 | 背景・基本文字色 |
| `--ember` | 琥珀〜深紅 | 蒸気・魔法の光のアクセント |

## ページアクセント色(承認制)

コア4色以外の色を使いたい場合は、ここに提案を追記してから人間の承認を待つこと。
承認前は実装に使わない。

### 提案中(未承認)

### --azure (天空青) [提案日: 2026-07-25]
- 色: #4e8ea0
- 使用予定ページ: 飛行船ドック(area-hero ビジュアル・アクセント)、天文台(予定)
- 理由: 飛行船ドックは「空」が主題。コア4色には青系がなく、現在のビジュアルが
  エメラルドと同系になっている。スチールブルー系を加えることで空・風・高度の
  イメージが明確になり、他エリアとの差別化が強まる。
- コアカラーとの関係: --emerald(深緑)と隣接する青緑系。--brass(真鍮)の暖色と対比。

### --arcane (魔法紫) [提案日: 2026-07-25]
- 色: #7460a0
- 使用予定ページ: 魔法陣召喚広場(season tag・accent)、決闘演武場(予定)
- 理由: 魔法陣・精霊召喚の「神秘・arcane」イメージには紫系が最も世界観に合う。
  現在はコア色のみで「魔法感」が薄い。--inkの深紺に対して補色方向の紫が映える。
- コアカラーとの関係: --ink(深紺)と類似色だが彩度が高く、背景から浮き出る。

### --silver (銀・時計) [提案日: 2026-07-25]
- 色: #9ba8b4
- 使用予定ページ: 時計塔(area-hero・歯車装飾)
- 理由: 時計塔は「精密機械・時間魔法」が主題。磨かれた銀色の歯車・針・文字盤の
  イメージに --brass(真鍮)より冷たい金属色が合う。クールグレー×真鍮の組み合わせで
  スチームパンクらしさが増す。
- コアカラーとの関係: --brass(暖色金属)の対となるクール金属色。--inkとも調和する。

### --crimson (深紅・演武) [提案日: 2026-07-25]
- 色: #a03c3c
- 使用予定ページ: 決闘演武場(accent・バッジ)
- 理由: 決闘・戦闘魔法のエリアには緊張感・迫力を表す深紅が適切。
  --ember(琥珀オレンジ)より赤寄りで「炎・血・勝負」のニュアンスを加える。
- コアカラーとの関係: --ember(琥珀)と同じ暖色系だが赤方向。--brass と組み合わせると
  ヴィクトリア朝の紋章的な重厚感が出る。
