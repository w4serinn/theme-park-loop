# 世界観チェックログ

`worldview-check` スキルの実行結果を記録する台帳です。
「提案中」の項目は、人間が確認して問題なければ `docs/ROADMAP.md` に
転記してください。転記済みの項目は「反映済み」に移動します。
テンプレートは下記です。
```
### 2026-07-27: [対象ページ名]

- インタラクション適合度:
  - (箇所) → (適合/未実装/要修正) + 理由
- 世界観の一貫性: (気づいた点)
- 実在サイト比較: (比較対象URLと選定理由 + 気づいた差分)
- 改善案:
  - [ ] (着手対象・完了条件・「使わないもの」まで明記したタスク文)
```
## 提案中

### 2026-07-27: トップページ

- インタラクション適合度:
  - 学院の3大体験カルーセル(`src/highlight-carousel.js`)のスライド切り替え
    → **要修正**。`.highlight-list.is-carousel .highlight-card { animation:
    highlight-fade 0.4s ease-out; }`(`opacity: 0 → 1`のみ)で、フェードだけの
    画面遷移に該当する。
  - カルーセルのアクティブドット `.highlight-carousel__dot.is-active`
    → **要修正**。`transform: scale(1.2);` によるただの拡大。
  - ナビゲーションカード(「学院を探索する」7枚)のアイコンホバー
    `.nav-card:hover .nav-card__icon`
    → **要修正**。`transform: scale(1.15);` によるただの拡大。
  - about-section・ticket-info-sectionの区切り(`.ornament-gear`、⚙️が9秒周期で
    回転、光彩付き) → **適合**。歯車の回転として蒸気機械系の質感を表現できている。
  - スクロール連動のセクションfade-in(`.reveal`、7セクション、
    `src/scroll-reveal.js`) → **要修正寄り**。`opacity` + `translateY(24px)`の
    汎用的なイージング(`ease-out`)のみで、蒸気機械/魔法どちらの質感も無い。
  - ヒーローCTAボタンのホバー(`background-color`/`color`の反転のみ)
    → 量産型4パターン(scale/box-shadow拡大/スピナー/fade遷移)には該当しないが、
    特別な質感も無い「未実装」寄り。
  - ローディングスピナー: 該当箇所なし(静的サイトで非同期ローディングが存在しない)。
  - 参考: highlight-card・nav-cardのホバー時`translateY(-3px〜-4px)`リフトは、
    このスキルの4項目チェックリストには該当しないため指摘は参考程度に留める
    (`docs/ROADMAP.md`の「ページ制作の品質方針」側では既に別途、リンクカードは
    arrow移動・border変化を優先する方針が明記されている)。

- 世界観の一貫性: 目立った矛盾は見つからなかった。魔法暦・魔導工学・学科名などの
  固有名詞が全セクションで一貫して使われている。アクセス欄に「電車・バス・お車」
  という現実的な交通手段が並ぶが、「転移魔法陣」も併記されており、
  「蒸気機械と魔法が共存する」という世界観の前提(現実的な技術とファンタジーの
  ハイブリッド)の範囲内と判断した。

- 実在サイト比較: [ムーミンバレーパーク公式サイト](https://metsa-hanno.com/)
  (埼玉県、物語世界観を軸にした中規模テーマパークという点で近い)と比較。
  - 情報密度: 先方はニュース/イベント/アクティビティ/展示/ショー/物販/飲食/
    ワークショップ/ホテル/SNS埋め込みなど10カテゴリ超を階層的に整理。当サイトの
    トップページも8ブロック程度(学院紹介・3大体験・7ページ導線・今月の学院・
    来場案内・アクセス概要・お知らせ)を持ち、breadth自体は近い水準。
  - 導線: 先方はヘッダー直下に「チケット購入」「開園時間・駐車場」「アクセス」を
    常時固定表示し、どのページからもチケット購入に1クリックで到達できる。
    当サイトはヘッダーに「入学願書」への通常リンクはあるが、チケット購入への
    強調導線(常時表示のCTAボタン等)は無く、トップページのヒーロー内CTA1箇所のみに
    依存している。
  - 演出: 先方は画像スライダー・波線デコレーション・「ぜんぶ見る」の段階的開示など
    比較的控えめで実用重視。当サイトは歯車回転など世界観要素を既に持てている点で
    差別化できている一方、カルーセル/ホバーの一部が量産型パターン(fade/scale)である
    点は先方の「無難だが破綻していない」演出と比べても見劣りする。

- 改善案:
  - [ ] (S) 3大体験カルーセルのスライド切り替え演出を、単純なopacity fade
        (`highlight-fade`)から、歯車の噛み合わせを想起させる短いメカニカルな
        トランジション(例: 前のカードが機械的にスライドアウトしつつ僅かに回転し、
        次のカードがcubic-bezierの急停止イージングでカチッと止まる)に変更する。
        **使わないもの**: scaleによる拡大、box-shadowの拡大、単純なfadeのみの遷移。
  - [ ] (S) カルーセルのアクティブドットの`scale(1.2)`を、点灯する魔法陣の光点
        (`text-shadow`やopacityの明滅で「アクティブ」を示す発光表現)に置き換える。
        **使わないもの**: transform: scaleによる拡大。
  - [ ] (S) nav-cardホバー時のアイコン`scale(1.15)`を、アイコンが淡く発光する、
        または歯車系アイコンの場合はわずかに回転するなど、蒸気機械/魔法の質感が
        ある表現に置き換える。**使わないもの**: transform: scaleによる拡大。
  - [ ] (M) ヘッダー(`partials/header.html`)に「入学願書(チケット)」への常時
        アクセス可能な強調CTAを追加できないか検討する(例: ヘッダー右端にボタン化
        したリンクを配置)。全ページ共通パーツのため影響範囲が広く、着手前に
        `docs/ROADMAP.md`の「0. 共通パーツ」として扱うか判断すること。
  - [ ] (S) スクロール連動fade-in(`.reveal`)のイージングを、汎用的な`ease-out`から
        機械式(急に加速して直前でカチッと止まる)のcubic-bezierに差し替え、
        蒸気機械の質感と両立できるか試験導入する。**使わないもの**: 既存のまま
        の単純なopacity+translateYのみで終わらせること。
